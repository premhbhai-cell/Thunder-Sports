THUNDER SPORTS - STATIC WEBSITE
Open index.html in a browser (or upload the whole folder to your hosting).

SAME header + footer + mobile bottom bar (Shop / Wishlist / Request / Cart / My account) on every page.
All of it lives in ONE place: site.js (functions header(), footer(), toolbar()). Change it once -> changes on all pages.

Products: edit site-data.js (name, price, oldPrice, images). Photos are in the products/ folder.
Cart + wishlist are saved in the browser (localStorage). Checkout/contact forms are demo forms (no backend).
Categories other than Cricket Bats have no products yet - add them in site-data.js with category 'Helmets', 'Cricket Kits', etc.
